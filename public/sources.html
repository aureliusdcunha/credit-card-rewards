If automatic search misses the card page, paste the issuer's official HTTPS URL here. It must match the selected bank; readable terms/PDF links on that issuer's site will be tried automatically.

To add a new card, leave Existing card blank. Run extraction, review the JSON and source quotes, then select “Create card & publish reviewed rules”. Only allow-listed official issuer domains are accepted.

If publishing reports that migration 0002_joining_fee.sql is missing, open Cloudflare D1 → credit-card-rewards → Console and run ALTER TABLE cards ADD COLUMN joining_fee REAL; once. This schema change is required before any card can be published.
